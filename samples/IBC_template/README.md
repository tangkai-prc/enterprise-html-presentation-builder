# IBC Template Sample

This sample preserves the current IBC/NARI HTML presentation baseline for future development.

## Contents

- Source PowerPoint templates are local-only inputs and are intentionally excluded from git; the retained analysis and previews document the visual/layout reference.
- `analysis/IBC_template-analysis.md`: template analysis and layout strategy.
- `analysis/IBC_template-agenda-layout.md`: agenda page coordinate extraction.
- `analysis/IBC_template-agenda-layout.json`: structured agenda extraction output.
- `prototypes/IBC_template-prototype.html`: current browser HTML prototype.
- `prototypes/IBC_template_assets/`: extracted PPT media used by the prototype.
- `projects/ibc_presentation_title/brief.md`: project brief fixing the current title and default chapter setup.
- `template-derived/previews/IBC_template-pptx-preview.png`: visual preview exported from the source PPTX for manual comparison.
- `template-derived/previews/IBC_template-html-preview.png`: rough visual preview of the HTML prototype for regression comparison; use browser review for final layout judgement.
- `template-derived/raw-media/hdphoto1.wdp`: original extracted PPT media retained for completeness; it is not currently used by the HTML prototype.

## Tracking Rule

Reviewed derived files here are intended to be tracked by git as stable development samples. Keep source PPTX masters and runtime experiments local; copy only reviewed analysis, previews, and prototype artifacts into this sample.
