## 关键目录页定位建议

- 中文目录页的 `目录` 来自 `slideLayout2.xml`，位置约 `x=65.52, y=177.38, w=75.73, h=365.08`。
- 中文目录页的 `CONTENTS` 来自 `slideLayout2.xml`，位置约 `x=177.2, y=238.87, w=62.07, h=242.2`。
- 中文目录页 `CONTENTS` 的文本配置：`bodyPr vert=eaVert`，段落 `algn=ctr`，无额外字符间距配置；run 为 `微软雅黑`，字号 `28 pt`，加粗，颜色 `scheme:bg1`。HTML 中应避免 `text-orientation: upright` 造成字母间距过大，优先使用 vertical writing mode + mixed orientation。
- 英文目录页的 `CONTENTS` 来自 `slideLayout3.xml`，位置约 `x=109.14, y=144.79, w=75.73, h=430.48`。
- 章节数字 1-4 来自目录版式，统一 `x=295.94, w=64.31, h=90.29`，y 约为 `112.34 / 247.31 / 382.39 / 517.46`。
- 章节数字 XML 读取结果：`1` 为 `#016F67`、`Arial Black`、50 pt、加粗；`2/3/4` 为 `scheme:bg1`、`Arial Black`、50 pt、加粗。目录版式 XML 中未直接写入 `#7F7F7F`，HTML 渲染按人工确认规则将非活动章节数字覆盖为 `#7F7F7F`，并保持加粗。
- 章节文本占位符从 `x=375.38` 开始，宽度约 `754-767`，y 约为 `138.05 / 274.82 / 407.99 / 543.06`。
- 章节文字 XML 读取结果：活动章节文本显式为 `#016F67`、加粗；非活动章节文本多为占位符继承样式，无显式 run 颜色/加粗。目录版式 XML 中未直接写入 `#7F7F7F`，HTML 渲染按人工确认规则将非活动章节文字覆盖为 `#7F7F7F`，并统一加粗。
- 2/3/5 章节目录为 HTML 派生母版，分别复用中文 `slideLayout2.xml` 和英文 `slideLayout3.xml` 的目录框架；数字与文字的 x 坐标保持不变。
- 2 章节派生 y 坐标：数字约 `220 / 410`，文字约 `245.83 / 435.83`。
- 3 章节派生 y 坐标：数字约 `157 / 315 / 473`，文字约 `182.83 / 340.83 / 498.83`。
- 5 章节派生 y 坐标：数字约 `87 / 194 / 301 / 408 / 515`，文字约 `112.83 / 219.83 / 326.83 / 433.83 / 540.83`。
- `CONTENTS` 旁边的竖线来自目录版式的 `直接连接符 61`，位置约 `x=261.87, y=113.83, w=0, h=492.35`，线宽约 `3px`，颜色 `#00706B`。
- 母版 logo 来自 `slideMaster1.xml` 的 `ppt/media/image1.png`，位置约 `x=921.7, y=-3.65, w=358.3, h=83.97`。
- 目录页背景图来自版式图片 `ppt/media/image4.png`，中文页约 `x=0.57, y=208.91, w=1279.43, h=206.08`；英文页约 `x=0, y=201.26, w=1279.43, h=206.08`。
- 目录页不显示页码脚注；版式中的 `‹#›` 页码占位符不进入 HTML demo 的目录页。
